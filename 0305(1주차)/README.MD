1. Unix/Linux 핵심 철학 & 특징
3대 철학: 단순성(최소 기능), 이식성(C 언어로 작성되어 어디서나 실행), 개방성(소스 공개)

주요 특징: 다중 사용자/프로세스 환경, 쉘(Shell) 중심의 명령어 자동화, 트리 형태의 파일 구조, 뛰어난 네트워크 기능

2. 시스템 구조 (Architecture)
User(사용자) ➔ Shell(명령 해석) ➔ System Call(인터페이스) ➔ Kernel(핵심 OS) ➔ Hardware(장치)

Kernel의 역할: CPU(프로세스), 메모리, 파일 시스템, 장치 제어, 네트워크 통신을 직접 관리하는 OS의 심장

3. Unix/Linux의 역사와 계보
Dennis Ritchie가 C 언어로 Unix를 재작성하면서 대중화 시작

System V 계열: 상업용 Unix의 기반 (AIX, HP-UX, Solaris)

BSD 계열: 네트워크(TCP/IP) 혁신 주도 (Mac OS X의 기반)

Linux: 1991년 Linus Torvalds가 개발한 오픈소스 OS (GNU 소프트웨어와 결합)

4. 현대의 Unix/Linux 기반 OS
PC/서버: Linux, Mac OS X(BSD 기반), Solaris

모바일: Android(Linux 기반), iOS(Mac OS X 기반)
