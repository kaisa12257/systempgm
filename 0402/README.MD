1. 시스템 흐름
프로그램 ➔ C 라이브러리(fopen) ➔ 시스템 호출(open) ➔ 커널 ➔ 하드웨어
시스템 호출: 커널 영역에서 실행되는 OS 인터페이스.
라이브러리 함수: 시스템 호출을 쓰기 쉽게 감싸놓은 사용자 영역 함수.
2. 파일 입출력 함수 분류
기본 흐름: fopen() ➔ 입출력 처리 ➔ fclose()
텍스트 (가독성):
문자: fgetc(), fputc() (파일 끝은 EOF 반환)
줄 단위: fgets(), fputs()
포맷: fscanf(), fprintf()
이진 (성능/구조체 저장):
블록 단위: fread(), fwrite() ➔ 구조체 데이터를 메모리 그대로 쓰고 읽음.
3. 임의 접근 (Random Access)
fseek(fp, 이동거리, 기준) : 파일 포인터 위치 이동
기준: SEEK_SET(시작), SEEK_CUR(현재), SEEK_END(끝)
ftell(fp) : 현재 위치 확인 / rewind(fp) : 처음으로 리셋
4. 입출력 버퍼 (Buffer)
목적: 느린 하드웨어 I/O 성능 향상을 위해 데이터를 모아서 한 번에 처리.
주의점: 화면 출력이 늦어지거나 순서가 꼬일 때 fflush(stdout);으로 버퍼를 강제 비움.
5. 표준 스트림 & 객체
FILE 구조체: 내부적으로 버퍼 포인터와 파일 디스크립터(정수 값)를 관리하는 객체.
자동 오픈 스트림: stdin(키보드), stdout(화면), stderr(오류 출력)
