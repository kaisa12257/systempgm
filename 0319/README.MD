
1. 파일 시스템 특징
모든 것은 파일: 디렉터리, 장치도 모두 파일로 취급.
파일의 구성: 메타데이터(파일 정보) + 실제 데이터.
디렉터리 구조: 루트(/) 기준 트리 구조. /home(사용자), /bin(명령어), /etc(설정), /dev(장치).
2. 파일 권한 및 변경 (중요)
권한 구성: 사용자(u) / 그룹(g) / 기타(o) ➔ 각 r(읽기), w(쓰기), x(실행) 부여.
8진수 표기: 755(rwxr-xr-x), 644(rw-r----)
명령어:
chmod : 권한 변경 (예: chmod 755 파일, chmod u+x 파일)
chown : 소유자 변경 / chgrp : 그룹 변경
3. 링크 (Link)
하드 링크: 원본과 같은 inode를 공유하는 실제 같은 파일.
심볼릭 링크: 원본 파일의 경로를 가리키는 바로가기 파일.
4. 핵심 명령어
mkdir -p : 하위 디렉터리까지 한 번에 생성
rm -r : 디렉터리 전체 삭제 (주의)
touch : 빈 파일 생성 및 시간 동기화
> / >> : 출력 결과를 파일에 덮어쓰기 / 추가하기
