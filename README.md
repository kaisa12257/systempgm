1. 프로세스의 정의 및 종류
개념: 현재 실행 중인 프로그램을 '프로세스'라고 하며, 고유 번호인 PID를 가집니다. 모든 프로세스는 부모 프로세스에 의해 생성됩니다.
시스템 프로세스: 운영체제의 자체 생태계 유지와 관리를 담당하는 프로세스입니다.
사용자 프로세스: 사용자가 내린 명령이나 프로그램을 실행하기 위해 생성됩니다.
데몬 프로세스 (Daemon): 사용자와 직접 상호작용하지 않고, 시스템 백그라운드에 상주하며 특정 서비스를 지원하는 프로세스입니다.
2. 프로세스 확인 및 검색 명령어
ps -ef : 시스템 내 작동 중인 모든 프로세스의 상세 정보(UID, PID, PPID 등)를 트리 형태로 출력합니다.
pgrep 특정명 : 조건에 매칭되는 프로세스의 PID 번호만 빠르게 조회합니다. (예: pgrep sshd)
3. 전면(Foreground) 및 후면(Background) 작업 제어
후면 처리: 명령어 끝에 &를 붙여 실행하면 다른 명령을 즉시 입력할 수 있습니다. (예: sleep 10 &)
상태 전환 단축키: Ctrl + C(프로세스 강제 종료), Ctrl + Z(실행 중인 전면 작업을 일시 정지 상태로 후면 배치)
fg / bg: 일시 정지된 후면 작업을 다시 전면으로 가져오거나(fg), 후면 상태에서 계속 실행되도록(bg) 전환합니다.
입출력 제어: 백그라운드 작업 시 출력 결과를 잃지 않도록 리다이렉션을 주로 병행합니다. (예: find . -name test.c > find.txt &)
4. 프로세스 강제 제어 및 시그널
kill: 특정 프로세스를 종료하기 위해 시그널을 전달합니다. (예: kill PID 또는 작업 번호 kill %1)
시그널 제어: 옵션을 생략하면 프로세스를 정상 종료시키는 SIGTERM이 기본으로 전송됩니다. 강제 종료 시에는 특정 시그널 번호를 명시할 수 있습니다.
wait: 지정한 자식 프로세스가 완전히 종료될 때까지 부모 프로세스의 실행을 대기시킵니다.
exit: 해당 프로세스를 즉시 종료하고 부모에게 종료 코드를 반환합니다.
5. 프로세스 우선순위 및 변경 (nice / renice)
nice 값 범위: 19부터 -20까지 존재하며, 값이 낮을수록(마이너스에 가까울수록) CPU 스케줄링 우선순위가 높아집니다. 기본값은 0입니다.
renice: 이미 작동 중인 프로세스의 우선순위를 동적으로 조정합니다. (예: renice -n 5 -p PID)
6. 프로세스 특수 권한 (SetUID / SetGID)
실제 사용자 ID (UID) vs 유효 사용자 ID (EUID): 보통은 두 ID가 동일하지만, 특수 권한 파일 실행 시에는 일시적으로 변동될 수 있습니다.
Set-User-ID (SetUID): 파일 실행 중에 프로세스의 유효 사용자 ID(EUID)가 실행한 사람이 아닌 '파일 소유자(보통 root)'의 권한으로 임시 상승합니다.
권한 표시: 소유자 권한 자리에 s로 표시됩니다. (예: 비밀번호 변경용 -rwsr-xr-x /bin/passwd)
설정 방식: chmod 4755 파일명 또는 chmod u+s 파일명 (8진수 맨 앞자리 4 부여)
Set-Group-ID (SetGID): 파일 실행 중에 해당 프로세스의 유효 그룹 ID가 파일 소유 그룹의 권한으로 임시 전환됩니다.
