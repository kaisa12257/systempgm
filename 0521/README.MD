1. 핵심 검색 및 텍스트 처리 유틸리티
find: find 디렉터리 -name "파일명" 형태로 이름이나 속성을 이용해 지정된 경로 아래의 파일을 추적 및 출력함
grep: grep 패턴 파일명 형태로 파일 내부에서 지정된 정규식 패턴 문자열을 검색하여 해당 줄을 추출함
sort: 텍스트 파일의 내용을 줄 단위로 정렬하며, 옵션에 따라 알파벳, 숫자, 역순 등으로 다양하게 정렬함
split / cat / paste: split은 대형 파일을 여러 소형 파일로 분할하고, cat은 결합 및 출력하며, paste는 파일들을 줄 단위로 가로로 병합함
AWK / 액션(action): 패턴 스캔 및 처리 언어로, 입력된 레코드의 특정 필드를 추출하고 지정된 액션(스크립트 블록)을 수행하는 강력한 필터링 도구임
2. 작업 예약 및 디스크 관리 (Chap 09)
cron / crontab: 주기적이고 반복적인 시스템 작업을 자동화하기 위해 설정 파일(crontab)에 시간 스케줄을 등록하여 백그라운드에서 상주 실행함
at: 주기적이지 않고, 향후 지정된 특정한 시점에 단 한 번만 명령어를 실행하도록 예약하는 명령어임
df / du: df는 시스템 전체 파일 시스템의 남은 디스크 공간을 확인하고, du는 특정 디렉터리나 파일이 차지하는 실제 디스크 사용량을 측정함
tar 아카이브: 여러 파일과 디렉터리를 속성을 유지한 채 하나의 .tar 파일로 묶는 도구이며, 압축 기능은 없음
gzip / compress: 파일을 압축하는 유틸리티로, gzip은 .gz 확장자를 생성하며 현대 리눅스에서 표준으로 사용되고 compress는 고전 방식임
3. Bash 셸 환경 제어 (Chap 10)
Bash 시작 과정: 사용자가 로그인하면 환경 설정 파일(/etc/profile, ~/.bash_profile, ~/.bashrc)을 순차적으로 읽어 복구 및 환경 변수를 구축함
alias: 복잡하거나 긴 명령어를 짧은 별명으로 등록하여 생산성을 높임 (예: alias ll='ls -al')
히스토리 (History): 사용자가 이전에 입력했던 모든 명령어 목록을 메모리 및 ~/.bash_history 파일에 기억하는 기능임
재실행: 히스토리 번호나 특수 기호를 사용하여 이전에 실행했던 명령을 타이핑 없이 즉시 다시 실행함 (예: !! 바로 전 명령, !nv nv로 시작하는 명령)
4. 개발 환경 및 컴파일 도구 (Chap 11)
gedit: 리눅스 GUI 환경에서 직관적으로 소스코드를 편집할 수 있도록 제공되는 기본 텍스트 에디터임
longest.c / gdb: C 언어 실습 예제 등을 포함하며, gdb는 실행 중인 프로그램의 내부 변수, 메모리, 레지스터를 추적하고 중단점(Breakpoint)을 잡는 소스 레벨 디버거임
메이크 파일 (Makefile): 수많은 소스 파일의 의존성을 정의하고 make 명령 한 번으로 컴파일, 링크 등 빌드 과정을 자동화하는 명세서 파일임
5. 파일 시스템 인프라 및 파일 입출력 (Chap 12)
하드 링크와 구현: 원본 파일과 완벽히 동일한 inode 번호를 공유하는 디렉터리 엔트리로, 원본이 지워져도 inode의 링크 카운트가 남으면 파일이 유지됨
심볼릭 링크: 윈도우의 바로가기처럼 실제 데이터 블록에 타깃 파일의 절대/상대 경로 문자열만 담고 있는 특수 파일임
시스템 호출 vs fopen(): 커널의 자원을 직접 호출하는 저수준 함수 체계와 달리, C 라이브러리의 fopen()은 내부에 입출력 버퍼를 두고 시스템 호출을 감싸 성능을 높인 텍스트 모드 전용 함수임
6. 프로세스 구조 및 모니터링 (Chap 13)
프로세스 이미지: 실행 파일이 메모리에 로드되어 코드(Text), 데이터(Data), BSS, 힙(Heap), 스택(Stack) 영역으로 분할 배치된 물리적 상태를 의미함
size 명령어: 컴파일된 이진 파일(Binary)의 코드 영역, 데이터 영역, BSS 영역의 실제 크기를 바이트 단위로 출력해 주는 도구임
프로세스 ID (PID): 커널이 현재 실행 중인 모든 개별 프로세스를 고유하게 식별하기 위해 부여하는 유일한 양의 정수 번호임
7. 시스템 관리 및 운영체제 기동 (Chap 14)
sudo: 일반 사용자가 자신의 계정 상태에서 temporary하게 root(최고 관리자)의 보안 권한을 대여하여 관리자 명령을 실행할 수 있도록 검증하는 명령어임
시스템 부팅: 컴퓨터 전원이 켜지면 ROM BIOS/UEFI가 부트로더(GRUB)를 실행하고, 부트로더가 커널을 메모리에 올려 초기화 프로세스(init/systemd)를 기동함
shutdown: 시스템을 안전하게 동기화하고 다수의 사용자에게 통고한 후, 안전하게 운영체제를 종료하거나 재부팅(shutdown -r now)하는 관리자 전용 명령어임
데몬 프로세스 (Daemon): 터미널을 가지지 않고 백그라운드 상주 상태로 부팅 시점부터 종료 시점까지 네트워크 요청이나 오디오, 인쇄 등 시스템 서비스를 대기 제어하는 프로세스임
