1. 커널 서비스와 시스템 호출 메커니즘커널의 5대 서비스: 파일 관리, 프로세스 관리, 메모리 관리, 통신 관리, 주변장치 관리작동 구조: 응용 프로그램 ➔ 시스템 호출 ➔ 커널 ➔ 하드웨어시스템 호출 실행 과정:사용자 프로그램에서 저수준 함수(예: open())를 호출합니다.라이브러리 내부에서 trap 명령어를 실행하여 CPU를 커널 모드(Kernel Mode)로 전환합니다.커널 내부의 실제 시스템 호출 코드가 자원을 제어하며 실행됩니다.작업 완료 후 결과를 반환하며 다시 사용자 모드(User Mode)로 복귀합니다.2. 자원별 주요 시스템 호출 요약파일 제어: open(), close(), read(), write(), dup(), lseek()프로세스 및 시그널: fork(), exec(), exit(), wait(), getpid() / signal(), kill(), sleep()메모리 및 IPC: malloc(), free() / pipe(), socket()3. 저수준 파일 입출력 함수 (형식 및 옵션)open() / creat() / close()형식: int open(const char *path, int oflag, [mode_t mode]); ➔ 성공 시 파일 디스크립터(fd) 반환, 실패 시 -1creat(path, mode)는 open(path, O_WRONLY | O_CREAT | O_TRUNC, mode)와 내부적으로 동일합니다.oflag 핵심 옵션 조합:기본: O_RDONLY(읽기 전용), O_WRONLY(쓰기 전용), O_RDWR(읽기/쓰기 겸용)추가: O_CREAT(파일 생성), O_TRUNC(기존 내용 삭제), O_APPEND(끝에 추가), O_SYNC(디스크 즉시 동기화)read() / write() / dup()read(fd, buf, nbytes): 파일에서 데이터를 읽어 버퍼에 저장하며, 읽은 바이트 수를 반환합니다. 파일 끝(EOF)에 도달하면 0을 반환합니다.write(fd, buf, nbytes): 버퍼의 데이터를 파일에 기록하며, 실제 기록된 바이트 수를 반환합니다.dup(oldfd) / dup2(oldfd, newfd): 파일 디스크립터를 복제하여 하나의 파일을 공유하게 만듭니다. 이들 fd는 동일한 파일 위치 포인터를 공유합니다.4. lseek()를 이용한 임의 접근 (Random Access)lseek() 함수: off_t lseek(int fd, off_t offset, int whence);파일 위치 포인터를 원하는 바이트만큼 이동시키며, 성공 시 이동된 현재 위치를 반환합니다.기준 위치(whence): SEEK_SET(파일 시작점), SEEK_CUR(현재 위치), SEEK_END(파일 끝)고정 크기 레코드 이동 기법:특정 $n$번째 구조체 레코드로 바로 점프: lseek(fd, n * sizeof(record), SEEK_SET);바로 직전 레코드로 한 칸 역진: lseek(fd, -sizeof(record), SEEK_CUR);
