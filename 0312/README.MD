
1. 리눅스 핵심 개념
특징: 다중 사용자(Multi-user), 다중 작업(Multi-tasking) 지원 OS
철학: 모든 개체(장치, 프로세스 등)는 '파일(File)'로 관리됨
구조: 최상위 루트(/)를 기점으로 하는 트리(Tree) 형태의 계층적 디렉터리 구조
디렉터리 기호: /(루트), ~(홈 디렉터리), . (현재 위치), .. (부모 디렉터리)
경로 구분: 절대 경로(/부터 시작하는 전체 경로) / 상대 경로(.이나 .. 등 현재 위치 기준 경로)
2. 기본 제어 및 파일 명령어 (형식: 명령어 [옵션] [대상])
위치 및 목록 확인
pwd : 현재 작업 디렉터리의 절대 경로 출력
cd : 디렉터리 이동 (예: cd ~ 홈 이동, cd .. 부모 이동)
ls : 목록 출력 (옵션: -l 상세정보, -a 숨김파일 포함, -al 모두 보기)
alias : 명령어 별칭 설정 (예: alias ll='ls -al')
파일 내용 확인
cat : 파일 내용 전체 출력
more : 페이지 단위로 화면 출력 (긴 파일용)
head / tail : 파일의 앞부분 / 뒷부분 일부 출력 (예: tail -f 실시간 로그 확인)
wc : 파일의 줄, 단어, 문자 수 출력
파일 조작
cp : 파일 또는 디렉터리 복사 (cp 원본 사본)
mv : 파일 이동 또는 이름 변경 (mv 원본 목적지)
rm : 파일 또는 디렉터리 삭제 (rm 파일명)
3. 관리, 도움말 및 고급 기능
시스템 관리 및 패키지
passwd root : 최상위 관리자(root) 비밀번호 변경
apt-get update : 패키지 목록 최신화
apt install gcc : 프로그램(예: gcc 컴파일러) 설치
도움말 확인
man : 표준 매뉴얼 출력 (가장 권장)
info : 상세한 설명 제공
--help : 핵심 옵션만 간단히 요약 출력 (예: ls --help)
