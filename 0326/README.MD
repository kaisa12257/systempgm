1. 시스템 호출 vs C 라이브러리 함수
작동 흐름: 사용자 프로그램 ➔ C 라이브러리 함수 ➔ 시스템 호출 ➔ 커널 ➔ 하드웨어
시스템 호출 (System Call): 응용 프로그램이 커널의 기능을 사용하기 위한 통로이며, 실제로는 커널 모드(Kernel Mode)에서 실행됨
C 라이브러리 함수: 시스템 호출을 일반 개발자가 쓰기 쉽게 한 번 더 감싸놓은 함수 (ANSI C 표준 제공)
핵심 비교:
실행 위치: 시스템 호출은 커널 영역 / 라이브러리 함수는 사용자 영역
사용 난이도: 시스템 호출은 어려움 / 라이브러리 함수는 쉬움
대응 예시: open() 시스템 호출은 fopen() 라이브러리 함수와 매핑 / write()는 printf()와 매핑됨
2. 유닉스 파일 시스템과 C 언어 파일 종류
유닉스 파일 특징: 모든 데이터(키보드, 마우스, 장치 포함)를 연속된 바이트 형태의 '파일'로 취급함
텍스트 파일: 사람이 읽을 수 있는 문자 기반 파일이며, 줄 바꿈 문자가 내부적으로 자동 변환됨
이진 파일 (Binary File): 메모리의 데이터를 바이트 그대로 저장하여 사람이 읽기는 어렵지만 속도가 빠르고 구조체를 그대로 저장하기에 효율적임
3. 파일 입출력 메커니즘 (스트림 및 구조체)
입출력 기본 3단계: 파일 열기(fopen) ➔ 데이터 입출력(fread/fwrite 등) ➔ 파일 닫기(fclose)
FILE 구조체: 파일 스트림의 정보(버퍼 포인터, 버퍼 크기, 상태 정보, 파일 디스크립터)를 담고 있는 명세서
파일 디스크립터 (File Descriptor): 운영체제가 내부적으로 특정 파일을 식별하기 위해 부여하는 정수(Integer) 값
4. 표준 입출력 스트림 및 주요 함수
자동 오픈 스트림: 프로그램 실행 시 stdio.h에 의해 자동으로 열리는 3가지 스트림
stdin: 표준 입력 (키보드)
stdout: 표준 출력 (모니터 화면)
stderr: 표준 오류 출력 (모니터 화면)
fopen() / fclose(): 성공 시 FILE 포인터를 반환하고 실패 시 NULL을 반환하며, 작업 완료 후에는 반드시 fclose()로 파일 자원을 해제해야 함 (실패 시 EOF 반환)
fgetc() / fputc(): 파일에서 한 문자씩 읽거나 쓰는 함수로, 파일의 끝이나 실패 도달 시 EOF(-1)를 반환함
